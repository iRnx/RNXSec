# RNXSec Wordlists

Este diretório é utilizado pelo RNXSec para armazenar wordlists e datasets usados pelos diferentes módulos.

## Datasets externos

Os grandes datasets externos não são versionados neste repositório.

Atualmente, o RNXSec pode utilizar localmente fontes como:

- RockYou
- SecLists
- Cybbaris Wordlists
- outras coleções compatíveis

Esses datasets devem ser instalados separadamente em `resources/wordlists/`.

## Wordlists internas

Futuramente, o RNXSec poderá incluir pequenas wordlists próprias em:

`resources/wordlists/builtin/`

Essas listas serão mantidas no próprio repositório.
